
# Then I take screenshot

## Description

"Capture a full-page screenshot at the current viewport. Held in-memory (and optionally written to DIFFY_SCREENSHOTS_DIR) until 'send screenshots to diffy with name' uploads the batch."

## Gherkin Step Definition

```
Then(/^(?:I |we )?take screenshot$)
```

## Usage Examples

- `Then I take screenshot`
- `Then we take screenshot`
- `And I take screenshot`
- `And we take screenshot`
- `Then take screenshot`
- `And take screenshot`
