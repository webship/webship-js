# videos/

Generated by Playwright when video recording is enabled. Default mode is
**off** — this directory stays empty unless you opt in.

## Enable recording

| How | Effect |
| --- | --- |
| `WEBSHIP_VIDEO=on npm test` | Record every scenario in this run. |
| `WEBSHIP_VIDEO=on-failure npm test` | Record every scenario, keep only failures. |
| Tag scenario `@video` | Force-record this one scenario (mode-independent). |
| `worldParameters.video.mode = 'on'` in `cucumber.js` | Persist recording for every run. |

## File naming

Default template: `{datetime}.{feature_file}.{scenario}.{status}.{ext}` —
e.g. `2026-05-13T01-47-01-567Z.video.Record_a_tiny_click_flow_with_emojis.PASSED.webm`.

Mid-scenario `When I save the current video as "name.webm"` overrides the
template for that scenario.

## What is gitignored

Everything except this README. `.gitignore` keeps `videos/*.webm` out of
the repo so binary recordings do not bloat history. Share via your CI
artefact store or attach to a PR description directly.
